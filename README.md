## 一、这是什么

一块高云 GW2A-18 上跑完的旋转倒立摆：

- **感知**：SA100 角位移传感器（PWM 占空比解码，856 Hz）+ 增量编码器（四倍频，824.5 counts/圈）+ MCP3201（电流采样）
- **控制**：1 kHz LQR 四状态反馈 + φ 外环串级 + 积分 + 死区前馈；能量泵起摆状态机
- **执行**：DRV8874 PH/EN，20 kHz PWM，占空比分辨率 2500 counts（0.04%）
- **交互**：OLED 三页菜单 + 板载数码管 + EC11 旋钮
- **遥测**：VOFA JustFloat 6 通道 @100 Hz，115200

**姿态控制全链路（感知 → 滤波 → 控制律 → PWM）100% 在 FPGA 内用 RTL 实现，没有任何 MCU 参与。** 这一点比参考方案（摆角经外置 ADC / MCU 采样转发）在合规上更干净。

## 五、编译与烧写

```powershell
cd LQR_Furuta_v1.1
& 'D:\Gowin\Gowin_V1.9.12.04_x64\IDE\bin\gw_sh.exe' build.tcl
# 期望：GowinSynthesis finish -> Bitstream generation completed
#       impl/pnr/LQR_end.fs，头注释 CheckSum 应为 0x2D55（1.0 为 0x6A6F）

& 'D:\Gowin\Gowin_V1.9.12.04_x64\Programmer\bin\programmer_cli.exe' `
    --device GW2A-18C --cable "Gowin USB Cable(FT2CH)" --run 2 `
    --fsFile "firmware\LQR_end1.1_0x2D55.fs"
# 成功标志：Status Code is: 0x00006020 + Finished.
```

> `build.tcl` 必须用 **UTF-8 无 BOM** 保存。带 BOM 时 gw_sh 会报
> `invalid command name "??pen_project"`。见 [docs/05_编码约定.md](docs/05_编码约定.md)。

## 六、操作说明

| 操作 | 行为 |
|---|---|
| `F10` 复位 | 全系统复位 |
| `D11` 短按 | 启动/停止（`run`）——启动后自动起摆，捕获即进平衡 |
| `D11` 长按 | 编码器计数清零（横臂位置归零） |
| 旋钮转动 | 主菜单切换图标；参数页滚动；轨迹页调目标；跟随中每格 ±18° |
| 旋钮短按 | 选中：参数页 / 轨迹页 / 跟随 / 正弦档位 |
| 旋钮长按 | 返回主菜单 / 退出参数页 |
| 串口发 `i` | 起摆泵能方向取反（在线 A/B，不用重烧） |

**数码管状态**：`0` 停 / `1` 起摆中 / `2` 平衡中 / `3` 轨迹页已选中 / `8` 故障（ADC 过流锁存）

## 七、版本链

```text
LQR_2.1（起摆 + LQR 雏形）
  → 3.0i（KDP130 + 双 3 点中值 + JUMP_MAX40，定版控制）
  → 4.0（+数码管 +轨迹页）→ 5.0（+旋钮跟随，v1/v2/v3）
  → 6.0（跟随 v3 + 野值爆发保持）→ 8.0（速度页 / 幅度档）
  → 9.0（跟随软着陆 / 光标修复）→ 10.0（多轮滤波与增益微调）
  → 11.0（正弦基准 sin_base + 轨迹页精简为两项）
  → LQR_end（定版：改名 + 文档/数据/算法说明同步，RTL 与 11.0 逐字节等价）
```

**回滚**：`LQR_11.0/firmware/` 下保留 2.1 ~ 11.0 全部历史码流（375 MB，未并入本包）。
按 CheckSum 识别：**0x6A6F = 本定版**。

## 八、必读：已知问题

本工程有若干**已定位但未修复**的问题，以及一批**推断尚未实测**的结论。写报告、答辩前请先读
[docs/04_已知问题.md](docs/04_已知问题.md)。其中最重要的三条：

1. **跟随阶跃已实测**：单格 18° 目标能站住（实测 +14.4°，静差 −3.6°，过冲 26° 后回落），
   但**大目标阶跃仍会掉摆**（拓展要求③只做了一半，遥测里仍没有 `phi_tgt` 通道）。
2. **时序余量 9 ps**，改任何 OLED 相关逻辑都可能违例。
3. **`UserCode` 是构建校验和，不是版本号**（`0x00002D55` == `CheckSum`），别把它当版本标识用。
